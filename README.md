# خارطة مراجعة سياسات ECC · ECC Policy Review Map

أداة لمراجعة الالتزام بالضوابط الأساسية للأمن السيبراني **ECC-2:2024** الصادرة عن الهيئة الوطنية للأمن السيبراني. تعمل في المتصفح، وبيانات التقييم تبقى على جهاز المستخدم.

A browser workbench for reviewing compliance with NCA's **Essential Cybersecurity Controls (ECC-2:2024)**. Assessment data stays on the user's device.

**الرابط:** https://daniyahalharb68i.github.io/ecc-policy-review-map/

> الأداة مستقلة، ولا تمثل الهيئة الوطنية للأمن السيبراني، ولا تحل محل أدوات التقييم الرسمية.

## ما تقدّمه

**التقييم**
- **النص الرسمي:** 108 ضوابط و92 ضابطًا فرعيًا بالعربية والإنجليزية.
- **ثلاث طبقات لكل ضابط:** موثّق، ومطبّق، وفعّال.
  - **«ملتزم»** = موثّق ومطبّق.
  - **الفاعلية** مؤشر منفصل، فـ«ملتزم» لا تعني أن الفاعلية قيست.
  - تكشف الأداة «الالتزام الورقي» و«الممارسة غير الموثقة»، والضوابط الملتزمة التي لا دليل لها.
- **من الدليل الإرشادي GECC-2:2026:** 546 مخرجًا متوقعًا، تظهر قائمةَ تحقق لكل ضابط، و548 بندًا من إرشادات التطبيق. هما فئتان منفصلتان.
  - مؤشر **«استكمال قائمة المخرجات»** يحسب ما أشّر عليه المقيّم، ولا يتحقق من محتوى المرفقات.
- **النطاق والانطباق:**
  - قبل تحديد نوع الجهة وإكمال أسئلة الانطباق، يكون انطباق الضوابط **«لم يُحدد بعد»** والنسب **أولية**.
  - الضوابط المشروطة تُستبعد بنصها الرسمي.

**التحليل والمعالجة**
- **خارطة معالجة** بثلاث مراحل، وقائمة مستقلة بـ«ضوابط تحتاج إلى تقييم».
- **سجل المخاطر** بخريطة حرارية، و**سجل الاستثناءات** بتواريخ الانتهاء.
- **محلل السياسات:** يقرأ PDF وWord والنص.
  - **إخفاء المعلومات الحساسة** داخل الجهاز، دون ذكاء اصطناعي: اكتشاف تلقائي، وكلمات يضيفها المستخدم، وتظليل يدوي بأسماء يختارها.
  - **نسخة منقّاة** بنفس صيغة الملف الأصلي. صفحات PDF الممسوحة ضوئيًا تُحجب ولا تُعدّ آمنة.
  - **فحص تغطية محلي** دون ذكاء اصطناعي.
  - **تحليل بمساعد ذكاء اصطناعي يختاره المستخدم** (Claude أو ChatGPT أو Gemini) بالنسخ واللصق. الطلب يُرسل بعد إخفاء المعلومات الحساسة، والأسماء الحقيقية تُعاد في النتيجة على الجهاز.

**التقارير والتصدير**
- **تقرير رسمي PDF** بالعربية أو الإنجليزية، يمكن قفله بكلمة مرور.
- **تقرير تنفيذي PDF** للإدارة العليا.
- **تقرير تفصيلي Word** لفريق GRC.
- **ملفات أخرى:**
  - Excel كامل.
  - قائمة طلب الأدلة (Word وExcel).
  - مسودات سياسات من النص الرسمي.
  - مواعيد في التقويم (.ics).
- **عرض النتائج** حسب المكونات الأساسية، والمقارنة بين الفترات، والضوابط الأعلى خطورة.

**العمل الجماعي (دون خادم)**
- **«مساحة الفريق»:** ملف مشفّر (AES-256) في التخزين المشترك للجهة، مثل OneDrive أو SharePoint.
  - دمج لكل حقل على حدة.
  - مزامنة منسّقة تعيد الدمج إذا كتب زميل في الوقت نفسه.
  - اكتشاف التعارضات مع الاحتفاظ بالقيمتين وبنسخة تعارض.
  - سجل تعديلات محلي.
- **حزمة فريق مشفّرة** للجوال أو للإرسال.
- **حدود مهمة:**
  - لا توجد حسابات ولا تحقق من الهوية في النسخة المحلية.
  - اسم العضو في السجل هو ما كتبه على جهازه.
  - **الأدوار والصلاحيات اتفاق داخل الفريق، لا تفرضها الأداة**، لأن أي شخص يملك كلمة مرور الملف يستطيع تعديله.
  - الأدوار المفروضة فعليًا متاحة في النسخة المنشورة داخل Claude فقط.

## الخصوصية والأمان

- **ما يبقى على الجهاز:** التقييم والمرفقات ونصوص السياسات.
- **ما يغادره فقط:**
  1. **تحميل المكتبات والخطوط:** من cdnjs وGoogle Fonts.
  2. **عدّاد الزيارات GoatCounter:** يستلم اسم الصفحة، ونوع المتصفح، وحجم الشاشة، والدولة التقريبية، دون ملفات تعريف ارتباط.
  3. **مؤشر الفجوات العام:** أرقام الضوابط فقط، إذا اختار المستخدم المشاركة بنفسه.
  4. **ما ينسخه المستخدم بنفسه** إلى مساعد ذكاء اصطناعي.
- **تشفير محلي اختياري:** AES-256-GCM بكلمة مرور، مع قفل تلقائي، و**نسخ احتياطية مشفّرة** تشمل المرفقات، و**نسخ تلقائية** على الجهاز، وتنبيه عند فشل الحفظ أو امتلاء التخزين.
- **سياسة أمان محتوى صارمة (CSP):**
  - لا يعمل إلا سكربتا الأداة، ويُعرفان بالبصمة.
  - **بصمات سلامة (SRI)** لكل مكتبة خارجية.
  - تحقق من نوع الملفات ومحتواها وحجمها.
  - تنقية كاملة لأي بيانات مستوردة.
  - تحييد صيغ Excel في ملفات CSV.
- تفاصيل الاختبارات في [`SECURITY-TEST-REPORT.ar.md`](SECURITY-TEST-REPORT.ar.md).

## الاختبارات

```bash
node tests/run-tests.js          # يبني الأداة ويشغّل الاختبارات في Edge أو Chrome دون واجهة
node tests/run-tests.js --open   # يعرض صفحة الاختبارات لتشغيلها في أي متصفح
```

تغطي الاختبارات:
- حالات الضوابط والنسب.
- قواعد الانطباق لكل نوع جهة.
- استيراد JSON وتصديره وتنقيته.
- الدمج والتعارضات والمزامنة المتداخلة.
- إخفاء المعلومات الحساسة، بما فيه حالات PDF العربية.
- التقارير بالعربية والإنجليزية.
- الأمان: الملفات، وCSV، وXSS، والتشفير، وSRI، وصفحات PDF الممسوحة.
- إمكانية الوصول: أسماء الحقول، وترتيب العناوين، ورابط التخطي.

تعمل الاختبارات تلقائيًا عند كل رفع إلى GitHub عبر GitHub Actions، وتتحقق أيضًا من أن الصفحة المنشورة `docs/index.html` هي آخر بناء من `src/`.

## البناء من المصدر

```bash
node src/build.js src      # src/out/index.html (نسخة Claude)
node src/mktest.js src     # src/out/test.html  (النسخة المستقلة مع CSP)
cp src/out/test.html docs/index.html
```

| الملف | المحتوى |
|---|---|
| `src/data.js` و`src/ccc-ar.js` | نصوص الضوابط، والدليل الإرشادي، وإحالات CCC مع ترجمتها غير الرسمية |
| `src/core.js` | نموذج البيانات، والطبقات، والانطباق، والحفظ |
| `src/views.js` و`src/reports2.js` و`src/grc.js` | الشاشات، والتقارير، والمخاطر، والاستثناءات |
| `src/redact.js` و`src/redact-export.js` | إخفاء المعلومات الحساسة والنسخ المنقّاة |
| `src/teamspace.js` | مساحة الفريق المشفّرة |
| `src/security.js` و`src/reliability.js` | التحقق من الملفات، والتنقية، والتشفير المحلي، والحفظ الموثوق |
| `src/pdf.js` و`src/exporters.js` | PDF وWord وExcel والتقويم |
| `docs/` | النسخة المنشورة، وملفات العمل دون إنترنت (`sw.js`، `manifest.webmanifest`) |
| `tests/` | الاختبارات الآلية (50 اختبارًا) |
| `tools/` | أدوات استخراج البيانات من الوثائق الرسمية (لا تدخل في بناء الأداة) |
| `.github/workflows/tests.yml` | تشغيل الاختبارات تلقائيًا |

## المصادر

- ECC-2:2024، الهيئة الوطنية للأمن السيبراني (بالعربية والإنجليزية).

- الدليل الإرشادي لتطبيق الضوابط الأساسية GECC-2:2026، النسخة الإنجليزية.
